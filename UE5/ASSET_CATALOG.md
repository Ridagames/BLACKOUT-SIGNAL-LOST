## Environment actor groups

- Main architectural shell and far bulkhead.
- Repeated structural ribs and frame members.
- Wall recesses, inset panels, access doors, hazard strips and status slots.
- Ceiling cable trays, pipe runs and hanging cable drops.
- Floor drainage channels, grates and inset metal plates.
- Six machine housings with vent slots and status lamps.
- Ceiling fixtures, safety posts, end-of-corridor signal terminal.
- Suspended dust-mote meshes.

## Important distinction

This is a procedural asset build: the script creates and saves editable UE material assets and places detailed mesh actors in the level. It does not create bespoke sculpted hero meshes or a final photorealistic texture library. The map and packages only exist after the script is run and saved by Unreal Editor; committing the Python source alone does not create binary Unreal assets.

## Authored OBJ source meshes

Source files are stored in `Content/SourceMeshes/` and imported automatically into `/Game/Meshes` when the editor generator runs:

- `SM_BLK_Generator.obj` — layered generator cabinet with feet, face plates, vent details, rails and bolts.
- `SM_BLK_WallTerminal.obj` — industrial signal terminal with screen bezel, side rails and mounting feet.
- `SM_BLK_CeilingLamp.obj` — layered overhead fixture housing and diffuser frame.
- `SM_BLK_DoorFrame.obj` — reinforced industrial doorway frame with cross members and corner plates.
- `SM_BLK_FloorGrate.obj` — framed floor grate with repeated metal bars.

These are editable polygon source meshes, not screenshots or pre-rendered illustrations. The script imports them as static mesh assets and places them into the intro map; the surrounding level architecture remains procedurally assembled from Unreal primitives.
