## Environment actor groups

- Main architectural shell and far bulkhead.
- Repeated structural ribs and frame members.
- Wall recesses, inset panels, access doors, hazard strips and status slots.
- Ceiling cable trays, pipe runs and hanging cable drops.
- Floor drainage channels, grates and inset metal plates.
- Six machine housings with vent slots and status lamps.
- Ceiling fixtures, safety posts, end-of-corridor signal terminal.
- Suspended dust-mote meshes.

## Important distinction

This is a procedural asset build: the script creates and saves editable UE material assets and places detailed mesh actors in the level. It does not create bespoke sculpted hero meshes or a final photorealistic texture library. The map and packages only exist after the script is run and saved by Unreal Editor; committing the Python source alone does not create binary Unreal assets.
