# Ressources du jeu

Placer ici uniquement des ressources originales ou dont la licence autorise la redistribution.

Structure proposée :
- `textures/` — textures basse résolution optimisées PS3
- `models/` — modèles 3D simplifiés
- `audio/ambience/` — ambiances et bruitages
- `levels/` — données des niveaux

Aucun gros fichier factice n'est inclus : la taille du jeu doit provenir de contenu réel.
